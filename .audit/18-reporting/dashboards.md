# Auditoría de Dashboards y Visualización

## 1. Propósito
Garantizar que la toma de decisiones se base en datos correctos.

## 2. Criterios
- Precisión de las métricas (Data Accuracy).
- Disponibilidad y rendimiento de los tableros.
- Relevancia para los interesados.

## 3. Pasos
1. Validar la fuente de los datos detrás de los gráficos.
2. Verificar latencia de actualización.

## 4. Evidencia
Validación de datos vs base de datos origen.
