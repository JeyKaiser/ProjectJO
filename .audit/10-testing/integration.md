# Pruebas de Integración

## 1. Propósito
Validar la interacción entre módulos y sistemas (DB, APIs, External).

## 2. Criterios
- Uso de entornos de test efímeros (Docker).
- Validación de contratos API.

## 3. Pasos
1. Auditar tests de contratos.
2. Revisar la integridad de los datos en tests.

## 4. Evidencia
Reportes de integración y logs de errores de contrato.
