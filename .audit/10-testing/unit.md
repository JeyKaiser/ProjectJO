# Pruebas Unitarias

## 1. Propósito
Validar la lógica de negocio aislada.

## 2. Criterios
- Aislamiento total (Mocks/Stubs de dependencias).
- Cobertura de caminos positivos y negativos (excepciones).

## 3. Pasos
1. Ejecutar suites de tests.
2. Inspeccionar mocks (¿son demasiado complejos?).

## 4. Evidencia
Reporte de ejecución de tests unitarios.
