# Pruebas de Regresión

## 1. Propósito
Asegurar que cambios nuevos no rompan funcionalidades previas.

## 2. Criterios
- Ejecución automática tras cada cambio.
- Cobertura de funcionalidades core.

## 3. Pasos
1. Auditar la suite de regresión actual.
2. Verificar tiempos de ejecución.

## 4. Evidencia
Reporte de estabilidad del sistema tras despliegues.
