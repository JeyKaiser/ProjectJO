# Auditoría de Rendimiento Frontend

## 1. Propósito
Maximizar la velocidad de carga y fluidez de la interfaz.

## 2. Criterios de Evaluación
- **Core Web Vitals:** LCP, FID, CLS.
- **Carga:** Tamaño de assets, lazy loading.
- **Render:** Optimización de componentes (memo, useMemo).

## 3. Pasos de Ejecución
1. **Auditoría Lighthouse:** Ejecutar reporte.
2. **Profiler:** Analizar tiempo de render.

## 4. Evidencia Requerida
- Reportes Lighthouse.
- Capturas de rendimiento en DevTools.
