# Auditoría de Pruebas de Carga

## 1. Propósito
Validar el comportamiento del sistema bajo condiciones extremas.

## 2. Criterios de Evaluación
- **Stress Testing:** Punto de ruptura.
- **Load Testing:** Comportamiento esperado.
- **Soak Testing:** Estabilidad a largo plazo.

## 3. Pasos de Ejecución
1. **Escenario:** Definir carga de usuarios concurrentes.
2. **Ejecución:** Usar herramientas como JMeter o k6.

## 4. Evidencia Requerida
- Gráficas de carga vs respuesta.
- Identificación de cuellos de botella bajo estrés.
