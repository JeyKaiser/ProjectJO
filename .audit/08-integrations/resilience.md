# Auditoría de Resiliencia en Integraciones

## 1. Propósito
Garantizar que el sistema no colapse ante fallos de dependencias externas.

## 2. Criterios de Evaluación
- **Circuit Breakers:** Implementación de patrones de corte.
- **Timeouts:** Configuración adecuada.
- **Retries:** Estrategias de reintento inteligente.

## 3. Pasos de Ejecución
1. **Prueba de Fallo:** Simular caída del servicio externo.
2. **Revisión de Configuración:** Verificar tiempos de espera.

## 4. Evidencia Requerida
- Evidencia de fallos en cascada.
- Configuración de Circuit Breakers.
