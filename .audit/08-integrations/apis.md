# Auditoría de APIs de Integración

## 1. Propósito
Asegurar comunicaciones robustas y estandarizadas con sistemas externos.

## 2. Criterios de Evaluación
- **Protocolos:** REST, SOAP, gRPC, Webhooks.
- **Seguridad:** Autenticación (API Keys, OAuth), cifrado (TLS).
- **Documentación:** Swagger/OpenAPI o WSDL.

## 3. Pasos de Ejecución
1. **Auditoría de Endpoints:** Revisar contratos de API.
2. **Seguridad:** Verificar autenticación de entrada y salida.

## 4. Evidencia Requerida
- Ejemplos de payloads de API.
- Reporte de endpoints sin autenticación o con credenciales débiles.
