# Auditoría de Intercambio de Datos

## 1. Propósito
Evaluar formatos y protocolos de intercambio de información masiva.

## 2. Criterios de Evaluación
- **Formatos:** JSON, XML, CSV, Parquet.
- **Validación:** Esquemas (JSON Schema).
- **Seguridad:** Cifrado en tránsito y reposo.

## 3. Pasos de Ejecución
1. **Auditoría de Formatos:** Revisar esquemas de intercambio.
2. **Integridad:** Validar checksums o firmas digitales.

## 4. Evidencia Requerida
- Ejemplos de archivos de intercambio inválidos.
