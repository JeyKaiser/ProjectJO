# Auditoría de Pruebas de Seguridad

## 1. Propósito
Validar la postura de seguridad mediante pruebas proactivas.

## 2. Criterios de Evaluación
- **SAST/DAST:** Integración en CI/CD.
- **PenTesting:** Pruebas externas o internas.

## 3. Pasos de Ejecución
1. **Revisión de Pipeline:** Verificar si los tests de seguridad corren en el CI.

## 4. Evidencia Requerida
- Resultados de escaneos automáticos de seguridad.
