# Auditoría de Privacidad de Datos

## 1. Propósito
Proteger la información de identificación personal (PII).

## 2. Criterios
- Anonimización/Seudonimización de datos en entornos no productivos.
- Gestión del consentimiento del usuario.
- Derecho al olvido (borrado efectivo de datos).

## 3. Pasos
1. Validar procesos de borrado de datos (soft vs hard delete).
2. Revisar si datos sensibles se exponen en logs o backups.

## 4. Evidencia
Reporte de cumplimiento de borrado de datos.
