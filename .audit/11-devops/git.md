# Gestión de Código (Git)

## 1. Propósito
Estandarizar el flujo de trabajo y la trazabilidad.

## 2. Criterios
- Estrategia de branching clara (GitFlow/Trunk).
- Commits descriptivos y vinculados a tickets.

## 3. Pasos
1. Auditar historial de commits.
2. Verificar políticas de PR (Code Review obligatorio).

## 4. Evidencia
Configuración de branches y reglas de repositorio.
