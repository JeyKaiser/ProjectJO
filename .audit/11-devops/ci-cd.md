# CI/CD (Integración y Despliegue)

## 1. Propósito
Automatizar la entrega de valor de forma segura.

## 2. Criterios
- Quality Gates (linting, tests, security).
- Despliegues automatizados hacia entornos.

## 3. Pasos
1. Auditar archivos de configuración del pipeline.
2. Verificar etapas de validación.

## 4. Evidencia
Logs de pipelines exitosos y fallidos.
