# Auditoría de Roles y Responsabilidades

## 1. Propósito
Asegurar la rendición de cuentas y la clara división de funciones.

## 2. Criterios
- Matriz RACI actualizada para proyectos.
- Segregación de funciones (SoD - Segregation of Duties).

## 3. Pasos
1. Revisar accesos a sistemas productivos (¿quién tiene permiso de escritura?).
2. Verificar si existen dueños claros para cada servicio.

## 4. Evidencia
Matriz RACI, logs de acceso con rol asignado.
