# Auditoría de Seguridad Operacional (Safety)

## 1. Propósito
Asegurar que el sistema no comprometa operaciones físicas o críticas.

## 2. Criterios
- Failsafes: Comportamiento del sistema ante errores de hardware/sensor.
- Integridad operativa.

## 3. Pasos
1. Evaluar tiempos de respuesta de sistemas críticos.
2. Verificar mecanismos de parada segura (si aplica).

## 4. Evidencia
Reporte de comportamiento ante fallos críticos.
